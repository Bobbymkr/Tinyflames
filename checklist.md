# Tiny Flames — Development & Execution Checklist

**Project:** Tiny Flames Custom Candle Brand Website  
**Purpose:** To ensure smooth, professional, structured development from planning to launch  
**Recommended Use:** Track each task as Not Started / In Progress / Done / Blocked  
**Primary Focus:** Customization, international trust, emotional gifting, WhatsApp support, premium UX

---

# How to Use This Checklist

Use these status labels:

- `[ ]` = Not Started
- `[x]` = Done
- `[-]` = In Progress
- `[!]` = Blocked / Needs Confirmation

Each phase has:

1. Tasks
2. Deliverables
3. Acceptance criteria
4. Owner placeholder

Recommended owners:

- Client
- Project Manager
- UI/UX Designer
- Developer
- Content Writer
- Marketing Lead
- QA Tester
