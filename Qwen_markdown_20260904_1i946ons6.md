# Tiny Flames — Final Website Blueprint

**Version:** 1.0  
**Status:** Client / Design / Development Ready Blueprint  
**Brand:** Tiny Flames  
**Primary Market:** Indian customers worldwide  
**Future Market:** Global expansion after validation  
**Core Focus:** Customized candles, emotional gifting, international trust, WhatsApp-first support

---

# 1. Executive Summary

Tiny Flames should not be built as a normal candle store.

It should be built as a **warm, emotional, personalized gifting experience** that helps customers express feelings across distance.

The website must feel:

- Warm
- Personal
- Premium
- Handmade
- Trustworthy
- Calm
- Effortless

The primary business objective is to enable customers to easily:

1. Discover meaningful candle gifts
2. Customize candles with names, messages, dates, photos, scents, and packaging
3. Trust the brand for Indian and international delivery
4. Complete purchases with minimal friction
5. Contact a human easily through WhatsApp for support or bulk inquiries

# 7. Global Design System

## 7.1 Visual Mood

The website should feel like candlelight warmth: soft, warm, intimate, premium, and calm.

Avoid:
- Loud discount banners
- Too many animations
- Cold corporate luxury
- Cluttered layouts
- Overly bright colors

---

## 7.2 Color Direction

| Usage | Suggested Color |
|---|---|
| Background | Warm ivory / soft cream |
| Primary text | Deep brown / charcoal brown |
| Primary CTA | Warm amber / burnt honey / clay gold |
| Accent | Muted terracotta / soft copper |
| Trust elements | Sage green / muted olive |
| WhatsApp | WhatsApp green or brand-neutral with WhatsApp icon |

---

## 7.3 Typography Direction

### Headings
Elegant, warm, readable serif or display font.

Examples:
- Fraunces
- Cormorant Garamond
- Playfair Display
- Libre Baskerville

### Body
Clean sans-serif.

Examples:
- Inter
- Work Sans
- Nunito Sans
- Source Sans Pro

### Accent
Optional handwritten-style font for emotional microcopy.

Use sparingly for phrases like:
- “Made for the moments that matter.”
- “Handpoured with love.”

---

## 7.4 Button System

### Primary Button
Used for the main conversion action.

Examples:
- Customize Your Candle
- Add to Cart
- Checkout Securely
- Get My Quote

Style:
- Rounded corners or soft pill
- Brand primary color
- Hover: slightly darker + subtle lift
- Loading: spinner + disabled state

### Secondary Button
Used for supporting actions.

Examples:
- Shop Best Sellers
- View All Gifts
- Request Sample

Style:
- Outline button
- Hover: soft fill

### WhatsApp Button
Used for human support.

Examples:
- Chat on WhatsApp
- Ask About This Candle
- Get Help on WhatsApp

Style:
- WhatsApp icon
- Green or brand-neutral button

### Ghost / Text Button
Used for low-priority actions.

Examples:
- Continue Browsing
- Learn More
- Clear Filters

Style:
- Text link with arrow or underline on hover

### Disabled Button
Used when required selections are incomplete.

Style:
- Reduced opacity
- Helper text below

---

## 7.5 Global Button Microcopy

| Situation | Microcopy |
|---|---|
| Empty cart | “Your flame is waiting. Start with a candle that carries their name.” |
| Added to cart | “Added to your gift.” |
| Photo too low resolution | “This photo may look blurry when printed. Please upload a higher-resolution image.” |
| Character limit reached | “Keep it short and sweet — 12 characters max.” |
| Required field missing | “Please add this detail so we can make it perfectly personal.” |
| Proof approval needed | “We’ll send your design proof within 24 hours. Production starts only after you approve it.” |
| International delivery note | “Made to order in 3–5 business days, then shipped internationally.” |
| Out of stock | “This candle is being lovingly restocked. Get notified when it returns.” |

---

## 7.6 Scroll & Animation Rules

| Element | Scroll Behavior |
|---|---|
| Homepage sections | Fade-up gently |
| Product cards | Slight hover lift |
| Collection banners | Static or very subtle zoom |
| Reviews carousel | Manual swipe, optional slow auto-scroll |
| Gift occasion cards | Horizontal snap scroll on mobile |
| Header | Sticky, slightly shrinks after scroll |
| Product page CTA | Sticky add-to-cart after main CTA scrolls out |
| Builder progress | Sticky progress bar on mobile |
| Footer | Normal scroll |

Animation style:
- Fade-up movement: 16–24px
- Duration: 400–600ms
- Ease: smooth ease-out
- Stagger delay: 80–120ms
- Hover lift: 2px maximum

Avoid:
- Heavy parallax
- Flashy sliders
- Too many moving elements
- Animations that delay content

---

## 7.7 Accessibility Requirements

- Visible focus states
- Alt text for all images
- Large tap targets on mobile
- Reduced motion support
- Readable font sizes
- Strong color contrast
- Visible form labels
- Keyboard-friendly navigation
